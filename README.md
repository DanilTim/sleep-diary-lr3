# SleepDiary — Лабораторная работа №3

Приложение-дневник сна для Android с умным будильником. Позволяет вести учёт сна, просматривать статистику и устанавливать напоминания об отходе ко сну и пробуждении.

---

## Функциональность

- **Дневник сна** — добавление, редактирование и удаление записей с датой, временем засыпания/пробуждения, оценкой качества и заметкой
- **Автоматический подсчёт продолжительности** — корректно обрабатывает переход через полночь (например, 23:00 → 07:00)
- **Статистика** — средняя продолжительность сна, средняя оценка качества, лучший сон, общее число записей
- **Гистограмма** — кастомный `View` с графиком продолжительности за последние 7 ночей, цвет столбца зависит от качества сна
- **Умный будильник** — два независимых будильника: напоминание об отходе ко сну и сигнал пробуждения 
- **Звук и вибрация** — будильник пробуждения воспроизводит системный рингтон в цикле, отключается кнопкой из уведомления

## Стек технологий

| Компонент | Технология |
|---|---|
| Язык | Kotlin |
| Платформа | Android (minSdk 21+) |
| Хранение данных | `SharedPreferences` + JSON-сериализация |
| Будильник | `AlarmManager.setExactAndAllowWhileIdle` |
| Уведомления | `NotificationCompat` + `NotificationChannel` |
| Список записей | `RecyclerView` |
| График | Кастомный `View` (canvas + `Paint`) |
| Звук | `MediaPlayer` + `RingtoneManager` |
| Сборка | Gradle |
| IDE | Android Studio |

## Запуск

1. Открыть проект в **Android Studio**
2. Подключить физическое Android-устройство **или** запустить эмулятор
3. Нажать **Run** (`Shift+F10`)

> ! На Android 12+ требуется разрешение `SCHEDULE_EXACT_ALARM` для точных будильников. Если будильник не срабатывает — проверьте настройки разрешений приложения.

---

## Разрешения

| Разрешение | Назначение |
|---|---|
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | Точные будильники через `AlarmManager` |
| `VIBRATE` | Вибрация при срабатывании |
| `POST_NOTIFICATIONS` | Уведомления (Android 13+) |
| `RECEIVE_BOOT_COMPLETED` | Восстановление будильников после перезагрузки |

## Технические детали

| Параметр | Значение | Описание |
|---|---|---|
| Хранилище | `SharedPreferences` | Записи сериализуются в JSON-массив |
| Сортировка записей | По убыванию `id` (timestamp) | Новые записи отображаются первыми |
| Будильник сна | Только уведомление | Без звука, обычное уведомление |
| Будильник пробуждения | Уведомление + звук + вибрация | Постоянное уведомление, кнопка «Выключить» |
| График | Последние 7 записей | Цвет столбца: зелёный (5) → красный (1) |
| Рекомендуемый сон | 8 часов | Отмечается синей линией на графике |
